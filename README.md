💰 About Spendwise

Spendwise – Smart Expense Tracker is a user-friendly web application designed to make personal expense management easier and more organized.

It provides a simple and interactive interface where users can manage their expenses and keep track of their spending. The project focuses on creating a clean design and a smooth user experience while making expense tracking simple and convenient.

Developed using HTML, CSS, and JavaScript, Spendwise is a frontend web development project that demonstrates the practical use of web technologies to build an interactive website.
